Auto Books

Claude Code

Every month someone sorts the bank export by hand for the accountant.

  • DoesSorts each transaction into a category and learns from every correction
  • ResultOctober: 63 of 67 sorted on its own. The 4 it isn't sure about go to a person
  • TestedOn 3 months it never saw: 86% sorted alone in month 1, 94% by month 3, 0 sorted wrongly
  • SafeguardBelow 70% sure it asks instead of guessing. No AI service, so nothing leaves the app
  • Tools usedClaude Code, Python (scikit-learn), Streamlit
Read more

Upload a month's bank export (or use the sample company). It sorts every payment into a category, totals money in, business costs and a rough VAT figure, and leaves anything it isn't sure about for a person. Confirm those, and next month the same suppliers are sorted automatically. The data is an invented year for a small Latvian company, written the way bank exports look.

Inbox Router

Claude Code + Gemini

Customer emails arrive in six languages, and the urgent or risky ones wait in the queue.

  • DoesSorts each email by topic and urgency, routes it, and drafts a reply in the customer's language
  • ResultFraud, hardship, complaints and data requests always go to a person. Routine ones get a draft
  • Tested96 emails with known answers: 95 sorted exactly right, 0 risky emails missed
  • AI mistakesRated a scam-call email as medium urgency, not high. It still went to a person, and the miss is shown on the test page
  • Tools usedClaude Code, Google Gemini, Python, Streamlit
Read more

The AI reads each email and suggests the topic, urgency, a short summary and a draft reply. Fixed business rules then decide the team, and force a person to review fraud, hardship, complaints, data requests or anything the AI is unsure about. The 96-email test covers 16 emails per language, including tricky ones: two problems in one email, sarcasm, missing diacritics, and a customer who paid a scammer.

Early Call

Claude Code

Collections calls customers once they're already late.

  • DoesScores new loans for the risk of going 30+ days late, with the reasons in plain words
  • Result40% of the loans on its call list really went late, against 15% at random
  • TestedTrained on months 1–18, tested on 6 months it never saw. A black-box model did no better, so the explainable one is kept
  • SafeguardDoesn't use gender, age, nationality or family status. Built for who to call early, not for refusing credit
  • Tools usedClaude Code, Python (scikit-learn), Streamlit
Read more

Each month's new loans get a risk score, and the riskiest go on a call list with the reasons behind every score. Try an application and watch the risk and reasons move, set your own costs to see what calling early is worth (about €2,218 a month with the sample numbers), and check how it behaves market by market. 6,472 invented loans over 24 months in 6 markets.

Statement Check

Claude Code + Gemini

Underwriters read every bank statement by hand to check the income an applicant stated.

  • DoesReads a bank statement and checks it against the loan application
  • ResultStated 6,500 PLN, salary about 4,200: flagged before anyone approves the loan
  • Tested12 tricky statements in 5 languages: 12 of 12 got the right verdict and the right reasons
  • SafeguardThe AI only reads the statement. Fixed rules make every check, and a person decides
  • Tools usedClaude Code, Google Gemini, Python, Streamlit
Read more

Gemini reads the statement (any language, any bank layout). Fixed rules then check the name, how recent it is, the income against what was stated, whether income is still coming in, undeclared loans, regular gambling and bounced payments, and list every check with the lines that support it. The test set includes the cases that catch people out: salary paid in two parts, a one-off bonus, irregular self-employed income, a similar but different name.

Planning the day 3 tools

Schedule-change alerts

n8n + AI

A match moves, and nobody tells camera 2.

  • DoesWatches the match schedule and messages the crew when a time changes
  • ResultA Telegram message: who is affected and who can cover
  • AI mistakesSaid the next match starts at 16:25. It couldn't start before 18:05. Now the code checks every time
  • Tools usedn8n, OpenAI, Google Sheets, Telegram
  • Bugs fixed7 found in testing and fixed
Read more

An AI agent checks the order of play every 15 minutes. When something changes, it works out the knock-on delays and crew clashes and sends a Telegram alert saying who is affected and who can cover.

The AI mistake in full: An alert said the next match would start around 16:25. It couldn't start before 18:05: delays weren't being carried down the court. Caught by reading the alert as a production manager would, and fixed in the code, so the AI only writes the message and never decides the facts.

Runs in a private n8n account, so the video is the demo.

When will the court finish?

Replit

Tennis has no fixed end time, so crews and broadcasts plan blind.

  • DoesPredicts when the last match on a court will end
  • Result22:30 most likely, 21:40–23:31 range, 4 h crew overtime
  • AI mistakesFirst version mixed in qualifying and tour matches, so every forecast was off
  • Tools usedReplit, Python, Streamlit
  • Bugs fixed7 found in testing and fixed
Read more

Predicts when the last match on a court will finish, from 35,000 real ATP Challenger matches (2018–2024), and how much crew overtime that means. Change the plan and the answer updates.

The AI mistake in full: The first version mixed in qualifying and tour-level matches, which run to different lengths, so every forecast was off. It now uses Challenger main-draw matches only and shows how many were removed and why.
