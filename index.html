v0

  • DoesPick what you need and see the season price instantly
  • Result€ 70,627.70 for 20 matches, and a one-page quote to sign
  • AI mistakesAI said remote saves €30,008. Real answer: €38,720. Caught by checking every number by hand
  • Tools usedv0 (Vercel)

Pick a package, the number of matches and the add-ons, and see the season price with volume discount and VAT, what remote production would save, and a one-page quote ready to sign.

The AI mistake in full: It said remote production would save €30,008. Against the quote on screen the real saving was €38,720: the €900-per-match travel cost was left out of both sides. Caught by recalculating every test case by hand.

Planning the day 3 tools

Schedule-change alerts

n8n + AI

A match moves, and nobody tells camera 2.

  • DoesWatches the match schedule and messages the crew when a time changes
  • ResultA Telegram message: who is affected and who can cover
  • AI mistakesSaid the next match starts at 16:25. It couldn't start before 18:05. Now the code checks every time
  • Tools usedn8n, OpenAI, Google Sheets, Telegram
  • Bugs fixed7 found in testing and fixed
Read more

An AI agent checks the order of play every 15 minutes. When something changes, it works out the knock-on delays and crew clashes and sends a Telegram alert saying who is affected and who can cover.

The AI mistake in full: An alert said the next match would start around 16:25. It couldn't start before 18:05: delays weren't being carried down the court. Caught by reading the alert as a production manager would, and fixed in the code, so the AI only writes the message and never decides the facts.

Runs in a private n8n account, so the video is the demo.

When will the court finish?

Replit

Tennis has no fixed end time, so crews and broadcasts plan blind.

  • DoesPredicts when the last match on a court will end
  • Result22:30 most likely, 21:40–23:31 range, 4 h crew overtime
  • AI mistakesFirst version mixed in qualifying and tour matches, so every forecast was off
  • Tools usedReplit, Python, Streamlit
  • Bugs fixed7 found in testing and fixed
Read more

Predicts when the last match on a court will finish, from 35,000 real ATP Challenger matches (2018–2024), and how much crew overtime that means. Change the plan and the answer updates.

The AI mistake in full: The first version mixed in qualifying and tour-level matches, which run to different lengths, so every forecast was off. It now uses Challenger main-draw matches only and shows how many were removed and why.

Crew & control-room scheduler

Lovable

Booking 20 people across four courts by hand: someone gets double-booked, or works past their shift without anyone noticing.

  • DoesDrag people onto matches. Clashes show up straight away
  • ResultA match runs long: later matches move, new problems turn red
  • AI mistakesSame person shown as both "overtime" and "not available": payroll would have paid it
  • Tools usedLovable
  • Bugs fixed18 found in testing and fixed
Read more

Drag crew onto matches or crew slots. It flags double-bookings, short rest breaks, missing roles and overtime. When a match runs long, everything after it moves and the new problems show in red.

The AI mistake in full: One camera operator showed as both "5 min overtime" and "not available" on the same match. Payroll would have paid overtime for someone the app said shouldn't be there.

Client report from messy logs

Claude Code

After a tournament, the data sits in five files typed by different people.

  • DoesTurns five messy log files into one checked client report
  • ResultA client PDF report plus a payroll and to-do file. Nothing guessed
  • AI mistakesA typo of 130 966 viewers would have shown as a record audience. Now held back
  • Tools usedClaude Code, Python, Streamlit
  • Bugs fixed12 found in testing and fixed
Read more

Checks every value, fixes obvious typos and lists them, holds back anything uncertain, and builds a PDF report for the client plus an internal file with crew overtime and a to-do list of data problems.

The AI mistake in full: A viewer count typed with an extra digit (130 966) would have gone into the client report as a record audience. Anything far above the usual for that round is now held back to confirm.

Cleans every name against the broadcaster's master list (Latvian letters, name order, capitals, duplicates), makes the on-screen caption, and explains each change. Anything uncertain is held back for a human.
